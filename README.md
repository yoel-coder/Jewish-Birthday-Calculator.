# Jewish Birthday Calculator

A modern React calculator for Hebrew birthdays and Bar/Bat Mitzvah dates. It asks whether the birth was before or after sunset, displays Jewish years in Hebrew letters, and shows the Hebrew parsha for the Shabbos before the Bar/Bat Mitzvah.

## Run on Windows

1. Install Node.js from https://nodejs.org if it is not already installed.
2. Unzip this folder.
3. Double-click **START-WINDOWS.bat** inside the unzipped folder.
4. Hold **Ctrl** and click the localhost link shown in the window.

You can also open the folder in Visual Studio Code and run `npm install`, followed by `npm run dev`.

An internet connection is needed the first time `npm install` runs.
